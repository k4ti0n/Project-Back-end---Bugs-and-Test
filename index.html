BugForge: bugs e testes num só lugar

Sistema de gerenciamento de bugs e testes para equipes de jogos, que acaba com os registros perdidos em mensagens dispersas.

Conheça a soluçãoVer o código

O problema

Durante o desenvolvimento de um jogo, os bugs encontrados são registrados em mensagens dispersas, em grupos de chat, e-mails e anotações soltas. Com isso, fica difícil saber quem está corrigindo o quê e se a correção foi realmente testada. Bugs voltam, testes se perdem e o time perde tempo reconstruindo o histórico.

A solução

📁 Cadastro de projetos

Cada jogo é um projeto, com seus membros e bugs organizados.

🐞 Registro de bugs

Cadastre bugs com descrição, projeto e responsável, tudo centralizado.

🔎 Listagem por status

Filtre os bugs por aberto, em andamento ou resolvido.

🔄 Atualização de status

Acompanhe o ciclo de vida de cada correção.

✅ Registro de testes

Guarde cada teste com seu resultado (aprovado ou reprovado).

Regra de negócio: um bug só pode ser marcado como resolvido após um teste aprovado.
Experimente a regra

Simulação no navegador (não usa a API real).

Como funciona

  1. Cadastrar o projeto (o jogo) e seus membros.
  2. Registrar o bug encontrado, vinculado ao projeto.
  3. Consultar os bugs listando por status e atualizando o andamento.
  4. Testar a correção e registrar o resultado do teste.
  5. Resolver o bug, liberado apenas com um teste aprovado.

Tecnologias

FastAPI

Cria as rotas da API de forma rápida e gera a documentação automaticamente.

SQLAlchemy

Mapeia as tabelas projetos, membros, bugs e testes para classes Python (ORM).

SQLite

Banco de dados leve em arquivo, que guarda todos os registros do sistema.

Pydantic

Valida os dados que entram e saem da API, garantindo formatos corretos.
